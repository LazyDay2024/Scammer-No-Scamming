Tool: built-in `image_gen.imagegen` (no API/CLI fallback). All final files are RGB PNG, 1920×1080. Generated originals: 1672×941; centre crop to exact 16:9 (1664×936), then resize with Python Pillow `Image.Resampling.LANCZOS`. Only this art directory was written; no commit and no Unity run.
